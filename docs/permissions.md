# 证券经纪业务权限

本文件定义证券演示库的业务行权限，独立于平台用户与数据库管理权限。JWT 的 sub 是平台用户名；服务端先校验平台用户和数据库授权，再读取该用户在当前数据库的业务身份绑定（employees.employee_id）作为 ${userId}。工具参数不能改变当前身份；改写工作台模拟身份需要独立的 impersonate 权限。${asOf} 用于演示管理范围日期判断，默认 2026-10-21T00:00:00Z；OAuth 的真实有效期始终按当前时钟判断。

## 资金账户与客户范围

1. 员工不存在或 status != active：客户与员工范围为空。
2. 在职 ADMIN：所有客户。
3. 其他在职员工：fund_accounts.manager_id = 当前员工，或者 fund_accounts.department_code 属于有效管理范围。两者取并集，得到可见资金账号。客户表仅显示这些账号对应的客户资料。

employee_scopes 每行仅指定一个 branch_code 或 department_code。分公司范围覆盖其全部营业部；营业部范围只覆盖该营业部。effective_date <= asOf 的日期，且 expiry_date 为空或大于该日期时有效。生效日含当天，失效日不含当天。不根据主管角色自动授予机构权限。

客户经理跨营业部服务时，其名下资金账户仍可见；主管范围按资金账户的开户营业部，而不是经理所属机构。客户表不保存营业部、分公司或客户经理。分公司通过 fund_accounts.department_code → departments.branch_code 关联。没有客户本人登录，没有旧租户、显式客户授权或拒绝模型。

## 员工与权限配置

在职员工能查询本人；有效机构范围能查询该机构所属员工。分公司范围包括分公司负责人和旗下营业部员工；营业部范围包含该营业部负责人和客户经理。范围内已离职员工可作为机构历史资料显示，但离职身份本身不能登录或读取员工表。总部分管人员可以同时持有多个分公司或营业部范围。

employee_scopes 仅在职管理员可查询，其他身份在执行前被 deny_unless 拒绝。公共机构和证券字典不按身份过滤。资金账户、证券股东号、委托、成交、流水、持仓和日结均通过 fund_account_no 限定可见范围。同一客户的其他账户不会因客户资料可见而获得授权。customers 通过可见账户对应的 customer_no 限定客户资料范围。stock_accounts 通过 fund_account_no 关联资金账户并继承账户权限；每个资金账户分别对应沪、深交易所股东号。
